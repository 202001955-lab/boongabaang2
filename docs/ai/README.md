# AI와 함께 작업하기

두 사람이 어떤 AI를 쓰더라도 이 저장소에 있는 규칙과 기록을 기준으로 작업한다.
개인 대화에만 남은 결정을 다음 사람이 알아야 한다면 해당 파일에 요약한다.

## 새 AI에 전달할 시작 문장

> 프로젝트 루트의 AGENTS.md를 먼저 읽고, 현재 브랜치와 워크트리 상태를 확인해 줘.
> docs/ai/tasks에서 이번 요청과 연결된 작업 기록을 찾아 이어서 진행해 줘.
> 다른 작업의 변경은 보존하고, 요청 범위에 맞는 스킬과 검증 절차를 적용해 줘.

구체적인 요청의 마지막에 원하는 완료 지점을 붙인다. 예: “로컬 화면만 보여 줘”, “검증하고 기존 PR에 반영해 줘”.
PR 생성 요청이 서비스 배포 요청까지 뜻하지는 않는다.

## 문서의 역할

| 파일 | 유지할 내용 |
| --- | --- |
| [AGENTS.md](../../AGENTS.md) | 모든 AI의 공통 규칙과 읽을 파일 안내 |
| [WORKFLOW.md](WORKFLOW.md) | 브랜치·워크트리·커밋·푸시·PR·병합·복구 정책 |
| [PROJECT.md](PROJECT.md) | 현재 구조, 실행·검증 경로, 중요한 제약 |
| [DECISIONS.md](DECISIONS.md) | 지속해야 할 결정과 이유, 변경 시 대체 기록 |
| [TASK_TEMPLATE.md](TASK_TEMPLATE.md), `tasks/` | 작업별 진행 상황, 검증 근거, 인수인계 |
| [.agents/skills](../../.agents/skills) | 반복 작업에 필요한 절차 |

AI는 변경과 함께 관련 문서를 수정한다. 사람은 문서를 일일이 다시 설명할 필요 없이
“현재 지침과 작업 기록부터 읽고 이어서 진행해 줘”라고 요청할 수 있다.

## 파일을 실제로 읽었는지 확인하기

AI에게 “이번 작업에서 읽은 지침·스킬·작업 기록의 경로와 작업할 브랜치를 알려 줘”라고 요청한다.
자동 읽기를 지원하지 않는 도구라면 위 시작 문장으로 직접 파일을 읽게 한다.
다른 도구의 전역 설정을 자동으로 수정하거나 설치할 필요는 없다.

Codex의 저장소 스킬 위치는 `.agents/skills/`이고, 프로젝트 지침은 `AGENTS.md`로 제공한다.
저장소를 복제한 뒤 해당 프로젝트 안에서 AI를 시작한다. 발견되지 않으면 새 세션에서 다시 확인하거나 파일을 직접 지정한다.
다른 AI의 자동 발견 방식은 도구마다 다르므로 같은 동작을 가정하지 않는다.

공식 기준: [스킬 발견 경로](https://learn.chatgpt.com/docs/build-skills),
[AGENTS.md 적용 방식](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

이 파일들은 팀의 작업 약속이다. GitHub의 브랜치 보호·필수 리뷰·필수 CI 설정을 자동으로 설치하지 않는다.
저장소 관리자가 서버 쪽 보호 설정을 적용하는 일은 별도 권한이 필요하다.
